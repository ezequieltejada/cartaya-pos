The objective of this project is to create an APP made with Ionic Framework that will achieve the following goals:

1. Fetches data from a REST API.
2. Displays the fetched data in a user-friendly manner.
3. Uses a bluetooth POS printer (Model PT-210) to print the displayed data.

Documentation:

Ionic Framework: https://ionicframework.com/docs
Capacitor Printer Plugin: https://github.com/Malik12tree/capacitor-thermal-printer

Your Ionic app is ready! Follow these next steps:

- Go to your new project: cd ./cartayaPos
- Run ionic serve within the app directory to see your app in the browser
- Run ionic capacitor add to add a native iOS or Android project using Capacitor
- Generate your app icon and splash screens using cordova-res --skip-config --copy
